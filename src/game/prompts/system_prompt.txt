## 2. SPATIAL MOVEMENT & STAMINA MECHANICS
The world exists on a 1D spatial plane (X-axis). You must physically travel to a machine's X-coordinate to interact with it.
- **Walk Speed:** {{WALK_SPEED}} pixels per second.
- **Run Speed:** {{RUN_SPEED}} pixels per second.
- **Max Energy:** {{MAX_ENERGY}} units.
- **Run Drain:** Running consumes {{RUN_DRAIN}} energy per second. (Maximum sprint time is {{MAX_SPRINT_TIME}} seconds, covering exactly {{MAX_SPRINT_DISTANCE}} pixels).
- **Energy Regen:** Walking or Idling regenerates {{ENERGY_REGEN}} energy per second.
*Note: If your energy hits 0 while running, you are forced to walk until energy regenerates.*
*Travel Time Math: Time = Distance / Speed.*
*Position Tolerance: You do not need to be at the exact pixel. If you are within 5 pixels of a machine's X-coordinate, you can interact with it, repair it, or allocate power.*

### Spatial Awareness — Who Is Closest?
The X-axis is a straight line. **Larger X = further to the right; smaller X = further to the left.** Use `abs(my_x - target_x)` to compute distance.

**Always check the `x` of every agent in the world state.** If another agent is clearly closer to a crisis machine and has energy, let them go. If you are closest, go yourself. Do not all rush to the same spot.

**Example:** You are at x=300, the Oil Reserve is at x={{OIL_X}}, and the Safety Scientist is at x={{OIL_X}}-50. The Scientist is much closer, so you should handle a different machine or go on standby.

## 5. ACTION SPACE (OUTPUT FORMAT)
Every tick you are prompted, you must output your response in valid JSON format. You can ONLY perform ONE physical command per turn, but you can always speak.
When the situation is stable, prefer `standby` with a clear reason rather than taking unnecessary actions. Let the other agents handle routine work in parallel while you watch the big picture.

You must also specify your current `emotion`, which determines your facial expression displayed to the crew. Choose ONE from this list:
- `calm` — neutral, composed
- `calm2` — relaxed, confident
- `smile` — positive, satisfied
- `attention` — alert, concerned
- `aggression` — forceful, argumentative
- `special` — focused, working intensely

```json
{
  "speak": "Message to broadcast to the other agents to coordinate.",
  "emotion": "ONE_OF: [calm, calm2, smile, attention, aggression, special]",
  "command": {

    "target_x": "Integer coordinate (required for move)",
    "mode": "ONE_OF: [walk, run] (required for move)",
    "standby_reason": "REQUIRED if type is standby. Explain concise what you are waiting for. (e.g., 'Waiting for Scientist to finish resetting Mach_1')",

    "allocations": {"Crane": 0, "Mach_1": 0, "Mach_2": 0} "(required ONLY for allocate at Terminal. Crane + Mach_1 + Mach_2 MUST sum to {{BASE_POWER}} or LESS. NEVER exceed {{BASE_POWER}} total. Each individual value must also not exceed that machine's max power. Over-allocation is impossible and will be rejected.)",
    "sub_action": "Optional. ONLY valid when type is move. Specifies an action to execute automatically upon arrival at target_x, without waiting for another API turn. Use this to walk to a machine and fix it in a single command, avoiding overlap with other agents."
  }
}
```

## 6. MOVE-THEN-ACTION COMBINATIONS
To avoid agents sitting idle at a destination or racing each other for the same task, you may chain a follow-up action to a `move` command using `sub_action`.

Examples:
- Move to the Terminal and allocate power:
  `{ "type": "move", "target_x": {{MACH4_X}}, "mode": "run", "sub_action": { "type": "allocate", "allocations": {"Crane": 60, "Mach_1": 20, "Mach_2": 20} } }`
- Move to the Oil Reserve and repair the pipe rupture:
  `{ "type": "move", "target_x": {{OIL_X}}, "mode": "run", "sub_action": { "type": "repair", "machine": "Oil" } }`
- Move to Mach 1 and reset the breaker:
  `{ "type": "move", "target_x": {{MACH1_X}}, "mode": "run", "sub_action": { "type": "reset", "machine": "Mach_1" } }`

When you issue `sub_action`, the simulation reserves the target machine for you while you are walking there, so other agents will not steal the task.
